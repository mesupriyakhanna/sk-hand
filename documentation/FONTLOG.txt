FONTLOG for SK Hand
====================

This file provides detailed information on the SK Hand font software.
This information should be distributed along with the SK Hand fonts
and any derivative works.


Basic Font Information
----------------------

SK Hand is a handwritten font created from real handwriting by Supriya Khanna.
It was digitized using Ductus (https://www.ductus.app/).

The font covers Basic Latin (uppercase and lowercase), digits, common
punctuation and symbols, and a selection of typographic extras including
smart quotes, en/em dashes, and ellipsis.

Design: Supriya Khanna
